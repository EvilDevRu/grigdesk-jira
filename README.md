# Jira Cloud для GrigDesk

Пакет `grigdesk-jira` версии **0.1.1**, драйвер трекера контракта 1.
Зависимостей и импортов ядра нет; требуется Node.js с поддержкой TypeScript без сборки.

Установите пакет обычным установщиком драйверов GrigDesk в папку `drivers/grigdesk-jira`.
Первый коммит, тег и публикацию репозитория выполняет владелец.

В настройках подключения заполните:

- **Портал** — HTTPS origin Jira Cloud, например `example.atlassian.net`.
  Схема `https://` подставляется; путь, query, hash и реквизиты внутри URL запрещены.
- **Email** — адрес аккаунта Atlassian.
- **Токен доступа** — API-токен этого аккаунта.

Драйвер показывает назначенные вам, поставленные вами и открытые задачи, поставленные другим.
Поддерживает создание с выбором проекта, правку, завершение и возобновление через workflow,
поиск пользователей и проектов, комментарии и метки. Номер задачи — числовой Jira id;
рядом сохраняется привычный ключ `PROJ-123`, ссылка ведёт на `/browse/PROJ-123`.

В карточке отображаются подзадачи. Чек-лист, таймер, вложения, виджеты, удаление и приёмка
в 0.1.1 отключены. Соисполнители и наблюдатели не поддерживаются: попытка правки даёт явную ошибку.
Срок хранится только датой, без времени суток. Завершение и возобновление зависят от доступных
переходов workflow и прав аккаунта.

Технический контракт, ограничения и проверки: [docs/README.md](docs/README.md).

Проверки из папки пакета:

```bash
node --test tests/*.test.js
```
