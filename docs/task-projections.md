# Проекции задач для доски и карточки

С версии 0.1.1 `src/mapping.ts` разделяет две проекции общих полей задачи:

| Поле | Списки: `task()` | Карточка: `detail()` |
|---|---|---|
| responsible | displayName строкой или null | `{ id: accountId, name: displayName }` или null |
| group | Имя проекта строкой или null | Отсутствует |
| group_name | Отсутствует | Имя проекта строкой или null |
| group_id | Отсутствует | Числовой id проекта или null |

Поиск REST v3 и запасной поиск v2 используют `task()`. Поэтому `listTasks()` и все три
списка dashboard (`tasks`, `toReview`, `created`) передают подписи, совместимые с проверкой
`isBoardTask` веб-доски GrigDesk. Объект в `responsible` или `group` отклоняет весь снимок.

`JiraSession.taskDetail()` использует `detail()`: форма правки получает исходный accountId
исполнителя и числовой id проекта. Так же разделяет списки и карточку стоковый Б24.
Остальные общие поля, включая автора, описание, статус, срок и метки, совпадают.
`taskPageData()` возвращает только обсуждение, пустые вложения, метки и подзадачи.

`tests/dashboard.test.js` повторяет правило `isBoardTask`, проверяет подписи и null в обоих
вариантах поиска и отклонение объектных полей. `tests/card.test.js` проверяет объект исполнителя,
поля проекта и отсутствие `group` в детали.
